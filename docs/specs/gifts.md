# Gifts

A paid way to send one framed photo and a handwritten postcard to one person or one group. Built from `design-ref/project/GiftCompose.dc.html` and `MeGifts.dc.html` (phone, 390×844); wider screens extend the phone design.
The rules are plain TypeScript in `src/app/intro/gifts/`, so the mobile app can import them unchanged.
TODO(server): gifts are saved in this browser. Nothing reaches another person yet.
Tests: `tests/gifts/`.

Phase 1 is the gift maker; Phase 2 adds checkout and the sent screen. Unwrapping, the shelf's gifts and the mailbox come next.

The design draws papers, sprockets and perforations with CSS repeating gradients, tears and tags with clip paths, and shadows with filters: none port to React Native. Here they're SVG patterns, polygons and drawn shadows, with plain linear gradients and transforms, so the look matches and ports. A test keeps CSS filters, blend modes, backdrop blur and repeating gradients out. The look is checked by hand against the design's numbers; the tests pin structure.
