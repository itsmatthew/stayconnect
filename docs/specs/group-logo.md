# Group logo

Each group has a logo: the small round picture that stands for the group wherever it appears as an avatar.
By default it's the group's initials on its color; any member can replace it with their own photo.
Tests: `tests/group-logo/`.

| ID | Behaviour |
|----|-----------|
| LOGO-1 | **Default logo.** Initials from the group name, upper-cased, at most 3 characters. Each word gives its first letter. A word containing a digit counts whole ("24", "4B") because a number is never split. A word starting with an apostrophe (’14, '14) is skipped. A word that would take the logo past 3 characters is skipped, never cut. If nothing fits, the logo is the name's first letter or digit. Madrid Crew → MC, Fall 24 → F24, Apt 4B → A4B, Hoops Since ’14 → HS, Family → F. The initials sit on the group's canopy gradient. |
| LOGO-2 | **Everywhere.** Every small picture of a group is its logo: the Messages pinned row and recents list (`docs/specs/messages.md`, MSG-1), the thread header seam (MSG-3), the group profile header (`docs/specs/group-profile.md`, GP-2) and the Daily 5 send picker (`docs/specs/daily5.md`, D5-11). Its accessible name is "‹Group› logo". |
| LOGO-3 | **Ring.** Every logo, default or custom, has a thin ring in the group's color (`palette.canopy`) outside a cream gap. |
| LOGO-4 | **Change it.** The group profile's header (`docs/specs/group-profile.md`, GP-2) has a button, "Change ‹Group› logo"; the thread's logo opens the profile instead (GP-1). It opens a dialog, "‹Group› logo": the current logo, "Choose a photo" (a plain file picker, `accept="image/*"`, so the camera roll on phones), then the picked photo in the cropper (LOGO-7). Save is enabled once a photo is picked. Cancel, the close button or the backdrop discards it. The saved logo is the cropped square as a JPEG, at most 512 px. Friends have no profile, so no button. |
| LOGO-5 | **Who changed it, and undo.** The dialog reads "‹Name› changed the logo · Oct 21" ("You changed the logo · Oct 21" for the user; with the year when it isn't the current one). A logo nobody has changed shows no line. "undo" restores the logo it had before the last change, the same as ornaments (`docs/specs/home.md`, HOME-17): one level only, and undoing the first change brings back the initials. Images that can no longer be restored are deleted. |
| LOGO-6 | **Shared by the group, and the demo switch.** Any member can change the logo, and the change shows for everyone in the group. TODO(re-evaluate when groups come from the database): there is no server yet, so the logo lives in this browser with the ornament changes (IndexedDB `nowandthen-ornaments`, `.demo` suffix with the switch on, `docs/specs/demo.md`, DEMO-3). With the switch off there are no groups, so no logos. |
| LOGO-7 | **Cropper.** A picked photo opens in a round cropper: drag (mouse or touch) to position it, pinch or scroll to zoom, plus a "Zoom" slider from 1× to 4×. The photo always covers the circle. Save keeps the square around the circle; saved before the cropper has measured the photo, it keeps the centered square. The ornament sheet uses the same cropper (HOME-14). |

Dragging, pinching and the crop's pixels are visual: jsdom has no layout, image decoding or canvas. The tests pin the rules (initials, who/undo, where the logo appears), the cropper's controls and that the crop area reaches the saved image. The canvas crop is injected as a stand-in, like `decode`. Drag and pinch are checked by hand on a phone.
